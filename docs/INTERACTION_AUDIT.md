# 按钮与功能交互审查

## 审查规则

- 所有 `Pressable` 必须有真实 `onPress` 或明确 `disabled`。
- 所有图标按钮必须有 `accessibilityLabel`。
- 所有会触发异步或权限请求的按钮必须有失败反馈。
- 所有破坏性操作必须有确认。
- 所有弹层必须有关闭路径。
- 嵌套按钮必须阻止事件冒泡，避免误触外层跳转。

## 自动化检查建议

发布前运行：

```powershell
npm test
npm run typecheck
```

并运行 Pressable 扫描，确保没有无事件按钮：

```powershell
@'
from pathlib import Path
for p in list(Path('app').rglob('*.tsx')) + list(Path('src').rglob('*.tsx')):
    s = p.read_text(encoding='utf-8')
    i = 0
    while True:
        start = s.find('<Pressable', i)
        if start == -1:
            break
        j = start + len('<Pressable')
        brace = 0
        quote = None
        while j < len(s):
            ch = s[j]
            if quote:
                if ch == quote and s[j-1] != '\\':
                    quote = None
            else:
                if ch in ('"', "'"):
                    quote = ch
                elif ch == '{':
                    brace += 1
                elif ch == '}':
                    brace = max(0, brace - 1)
                elif ch == '>' and brace == 0:
                    break
            j += 1
        tag = s[start:j+1]
        if 'onPress' not in tag and 'disabled' not in tag:
            line = s.count('\n', 0, start) + 1
            print(f'{p}:{line}: {tag[:220].replace(chr(10), " ")}')
        i = j + 1
'@ | python -
```
