## 二、我们已有的优势（继续保持）

1. **人物关系图谱（StarMap）** — 竞品都没有的"以人为中心"的记忆组织方式，差异化亮点
2. **灵感墙社区** — Day One / Journey 完全没有社交，我们有轻社区
3. **日漫风视觉体系** — Halftone 网点、墨线描边、贴纸面板，视觉差异化强
4. **草稿箱 + 自动保存** — 写作中途不丢失
5. **隐私分层（私密记忆 / 应用锁）** — 双重保护
6. **触觉反馈 + 减少动效无障碍** — 已有基础设施

## 三、功能完善建议（按优先级排序）

### P0 — 核心体验差距（必须有）

#### 1. 那年今日 (On This Day / Throwback)
**竞品参考**：Day One 的招牌功能，Journey 的 Throwback

**设计方案**：
- 首页 hero 卡片下方新增「那年今日」区块
- 展示 1/2/3 年前同日的记忆卡片
- 无记忆时展示写作提示
- 卡片带翻页效果（横向 ScrollView + snap）

**动画**：
- 卡片从下方淡入 + 轻微上移（已有 entrance 模式）
- 翻页时 spring 弹性过渡
- 触觉反馈 selectionFeedback

---

#### 2. 写作提示 / 每日灵感 (Writing Prompts)
**竞品参考**：Day One Prompts、Journey Daily Inspiration、苹果 Journaling Suggestions

**设计方案**：
- 新建 `src/data/prompts.ts`，内置 60+ 条中文写作提示
- 创建页 placeholder 区域上方展示一条提示（可刷新换一条）
- 提示分类：回忆类、感恩类、成长类、想象类
- 示例：
  - "今天最想留住的瞬间是什么？"
  - "如果给五年前的自己写一句话，你会写什么？"
  - "最近一次让你笑出声的事？"

**动画**：
- 提示文字打字机效果（逐字显现）
- 刷新按钮旋转 360° + 触觉反馈
- 提示区有轻微的浮动呼吸动画

---

#### 3. 连续记录天数 (Streak) + 写作统计
**竞品参考**：Day One Streak、Journey Stats

**设计方案**：
- 首页 metric 行新增「连续 N 天」卡片
- 「我」页面新增「写作足迹」区块：
  - 总记忆数 / 总字数 / 最长连续天数
  - 本月日历热力图（类似 GitHub 贡献图）
  - 最常记录的心情 Top 3
  - 最常出现的人物 Top 3

**动画**：
- 数字 count-up 滚动动画（从 0 滚到目标值）
- 热力图格子依次填充（stagger 入场）
- 心情分布用环形进度条动画

### P1 — 重要体验提升

#### 4. 天气 & 位置自动记录
**竞品参考**：Day One、Journey 都自动记录天气/温度/位置

**设计方案**：
- 记忆创建时自动获取当前位置（已有 location 基础）
- 调用免费天气 API（和风天气 / OpenWeather）获取当前天气
- 记忆数据结构新增 `weather` 字段：`{ temp, condition, icon }`
- 记忆详情页和卡片展示天气图标 + 温度
- 日历视图日期格子可展示天气小图标

**注意**：
- 天气 API 调用需异步，不阻塞写作流程
- 离线时跳过，不报错

---

#### 5. 地图视图 (Map View)
**竞品参考**：Journey 的招牌功能

**设计方案**：
- 时间线页顶部新增「地图」入口（与日历并列）
- 使用 `react-native-maps`（Web 用 Leaflet）
- 标记所有有位置的记忆，点击标记展示记忆卡片预览
- 支持按年份/人物筛选

**动画**：
- 地图加载时标记依次弹出（scale 0→1 + spring）
- 点击标记时卡片从底部滑入
- 筛选时标记重新动画定位

---

#### 6. 导出 / 分享
**竞品参考**：Day One PDF 导出、Journey 多格式导出

**设计方案**：
- 记忆详情页新增「分享」按钮
- 支持导出为：
  - 长图（适合社交分享，日漫风排版）
  - PDF（适合打印存档）
- 批量导出：设置页新增「导出全部为 PDF」

## 七、总结

我们的核心差异化（人物星图 + 日漫风 + 轻社区）是竞品没有的，需要继续强化。但在**基础日记功能**上有几个关键缺口：

1. **那年今日** — 日记应用的灵魂功能，必须补齐
2. **写作提示** — 降低写作门槛，提升留存
3. **连续天数** — 游戏化激励，养成习惯
4. **天气记录** — 增强记忆的情境感
5. **地图视图** — 旅行记忆的天然归属

动画方面需要从"基础反馈"升级到"情感化微交互"：
- 粒子效果（点赞、保存成功）
- 骨架屏（加载体验）
- 共享元素转场（页面连贯性）
- 视差滚动（空间层次感）
- count-up 数字（数据成就感）

每个动画都需遵循 `useReducedMotion` 无障碍规范，确保可关闭。
