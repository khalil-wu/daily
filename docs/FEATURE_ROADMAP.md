# 功能规划文档

## 当前已具备功能

### 记录

- 创建日记，支持正文、人物关联、心情、图片、位置、录音、私密模式。
- 编辑日记，复用创建页的大部分能力。
- 删除日记，并同步更新人物统计。
- 日记标题和摘要由正文或图片自动生成。
- 草稿正文和心情通过 `useDraftStore` 保留。

### 人物

- 创建人物，选择关系，填写备注。
- 编辑人物资料。
- 删除人物，删除后不删除已有日记，只解除关联。
- 人物详情页展示关联日记，并可直接为这个人写日记。
- 首页星图展示人物关系和最近状态。

### 时间线与搜索

- 时间线展示可见日记。
- 支持按全部、照片、私密筛选。
- 支持按年份筛选。
- 搜索页支持搜索人物，并跳转人物详情。

### 社区

- 可以从非私密日记里选择发布到社区。
- 社区 feed 展示公开内容。
- 搜索、通知、关注、转发、评论、喜欢入口均有事件。
- 点赞、关注、转发目前是会话级 UI 状态。
- 评论当前跳转到对应日记详情。

### 隐私与备份

- 应用锁支持 PIN，支持设备认证入口。
- 私密日记支持完全隐藏和隐藏正文。
- 私密设置页支持批量和单条调整。
- 备份页支持导出、恢复、合并、覆盖、替换和取消导入。
- 存储层已有 Web / Native 平台分离。

## P0：必须优先补强

### 交互完整性

- 持续运行 Pressable 扫描，确保没有无事件按钮。
- 给所有重要按钮补齐 pressed、disabled、accessibility state。
- 对可能误触的嵌套按钮使用 `event.stopPropagation()`。

### 写日记体验

- 将创建和编辑页重复逻辑抽成共享 hook。
- 增强草稿箱：支持多篇草稿、恢复、丢弃确认。
- 关闭页面时如果有未保存内容，弹出确认而不是直接丢失。
- 照片、录音、位置、人物、心情弹层保持统一交互。

### 社区基础闭环

- 关注、点赞、转发状态进入 store 持久化。
- 关注 Tab 根据关注状态过滤内容。
- 热门 Tab 根据互动数排序。
- 附近 Tab 在有位置权限时优先展示有位置的公开日记，没有位置时展示说明。

## P1：增强核心价值

### 评论系统

- 新增 `Comment` 数据类型。
- 社区帖子点击评论时打开评论列表。
- 支持发布评论、删除自己的评论。
- 评论数从真实评论数组计算，不再只用数字字段。

### 标签系统

- `MemorySummary` 增加 `tags: string[]`。
- 写日记页增加标签入口。
- 时间线支持标签筛选。
- 搜索同时搜索标签、人物、正文。

### 日历视图

- 新增日历入口，按日期查看记录。
- 有记录的日期显示轻量标记。
- 点击日期进入当天列表。

### 分享与导出

- 日记详情支持复制纯文本。
- 支持生成分享图片，包含标题、日期、正文摘要和照片。
- 备份之外提供“导出全部为文本”的轻量能力。

## P2：长期能力

### 云同步和账号

- 在明确隐私策略前不做云同步。
- 需要先设计端到端加密、恢复密钥、冲突合并。
- 登录不应影响离线本地记录能力。

### AI 辅助

- 可选 AI 总结一周记录。
- 可选从日记中提取人物、心情和标签建议。
- 所有 AI 功能必须明确告知用户是否会离开本机。

### 地图和位置

- 位置详情页显示更可读的位置描述。
- 可选地图预览。
- 支持按地点回看日记。

### 原生录音完善

- Native 端接入音频模块。
- 支持录音暂停、继续、试听、删除。
- 备份中包含语音元数据和文件引用。

## 数据模型建议

### MemorySummary

- 增加 `tags?: string[]`。
- 增加 `updatedAt?: string`。
- 增加 `communityVisibility?: 'private' | 'public'`。
- 增加 `draftId?: string`，用于草稿恢复关联。

### CommunityPost

- 增加 `authorId?: string`。
- 增加 `likedByMe?: boolean`。
- 增加 `repostedByMe?: boolean`。
- 增加 `followedAuthor?: boolean`。
- 增加 `createdAt: string`。

### Comment

- `id: string`
- `postId: string`
- `authorId?: string`
- `content: string`
- `createdAt: string`
- `deleted?: boolean`

### DraftMemory

- `id: string`
- `content: string`
- `personIds: string[]`
- `attachments: MemoryAttachment[]`
- `voiceNotes: MemoryVoiceNote[]`
- `location?: MemoryLocation | null`
- `mood?: string | null`
- `privacyMode?: MemoryPrivacyMode | null`
- `updatedAt: string`

## 每个新功能的交付要求

- 有明确入口位置。
- 有空状态、加载状态、错误状态。
- 有数据结构和持久化策略。
- 有 store 级测试。
- 有移动端 375px 验证。
- 有按钮事件扫描结果。
- 不引入与当前风格冲突的 UI。
