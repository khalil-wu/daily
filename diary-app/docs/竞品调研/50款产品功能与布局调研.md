## 二、全量过图后的核心布局模式

### 1. 首页是「模块 hub」，不是裸列表
- Day One：On This Day 照片排 + Daily Prompt 卡 + 照片导入
- Apple Journal：Insights 三项 streak + Places 地图 + 日记本计数
- stoic：问候语 + 仪式卡（晨间规划/睡前反思/感恩）+ 每日金句
- Diarly：问候 + streak 火焰 + memories 照片卡 + 底部心情行
- Happyfeed：throwback chip "6 Months Ago" + 感恩罐

### 2. 心情/天气永远一次点按
- Daylio 五表情一排、Moo 编辑器顶部天气图标组、Sunrise 内联心情条、DailyBean 全点按
- **跳页选择是反模式**——元数据必须内联就地完成

### 3. 编辑器排版铁律
- 大日期开头（Daybook 绿"27"、墨记"18"+月、Diarly 日期头）
- 心情天气第一排、媒体工具条沉底、格式靠选中或键盘细条
- 提示问题即骨架（Grid Diary 格、Prompted 提示+Dive Deeper、Five Minute 行标题）

### 4. 列表与回顾
- 左日期列（吾记/卡片日记/Diaro）；文件夹筛选 chips 置顶（Daybook）
- 回忆钩子人手一个：那年今日（Day One/Apple/Momento/Happyfeed/flomo）
- 量化仪表盘：Moo 心情指数、Bearable 因素相关性、flomo 热力图、Daylio Year in Pixels
- AI 洞察：Rosebud 周报（情绪地形+主题chips）、心光 AI 评论+每周来信

### 5. 标配与变现
- PIN/指纹锁是标配卖点（Diaro/Pixels/stoic/Daybook 全在截图里卖）
- 中文变现=外观：素忆信纸+字体、墨记信纸、手帐类素材商店、主题市场（Diarly 100+）
- 小组件全家桶（stoic/flomo/EMMO/念念都有 widget 截图）

## 三、对照「记得日记」的盘点（复刻状态）

**早已具备的竞品级能力**：streak 连续天数（TodayCard）、今日灵感提示卡+换一题、心情快选 chips 开写、写作目标进度、日记本多本+切换、标签/人物/地点/天气元数据、模板库、草稿/收藏/置顶/隐藏、时间线/年度回顾/里程碑/记忆胶囊、AI 追问/整理/理顺（≈Rosebud 追问）、AI 周记、地图/相册/搜索、主题外观系统、应用锁、云同步+多账号切换。

**本次复刻新增**（全部有过图依据）：
1. **「那年今日」首页横排回忆条**——Day One/Happyfeed 式，往年同月同日的日记卡直接上首页（`OnThisDay.tsx`）
2. **编辑器内联心情/天气快选行**——Daylio/Moo/Sunrise 式点按即得，替代跳页选择（`write.tsx` metaRow）
3. **列表心情快捷筛选行**——Daybook/Daylio 式，出现 ≥2 种心情时 tabs 下露出一行可点筛选（`index.tsx`）
4. **编辑器大日期头**——墨记/Daybook 式"18 三月·2026年 周四·21:30"置于正文之首，轻点改日期（`write.tsx`）

**仍值得做（下期候选）**：
- AI 主动评论已具备（`writeReply`/`shouldAutoReply`），下一步可做心光式"每周来信"长信或 AI 影集配文
- 板块式日记自定义板块（时光日记本式，需动数据模型）
- 咕卡/素材商店以外的轻量变现：信纸纸张、字体包（素忆式）

**不建议抄**：装扮小屋/养宠（念念暖暖）、社交广场/过客（吾记心岛）、咕卡素材店、情侣定位、实体书印刷、生活工具合辑。

## 五、第二遍：组件与动效对照（2026-11-21 复看全部截图）

第二遍专门从「UI 组件细节 / 动画动效 / 页面布局」角度再过全部截图，对照我们的实现：

**已具备且不输竞品**：按压缩放 PressableScale、列表分组卡片+滑动手势、FAB 45° 旋转展开菜单、底部面板弹簧升起+下拉关闭、弹窗 pop 缩放、骨架屏、下拉刷新、tab 图标弹簧上浮、编辑器内联快选行、日历格心情点、保存页入场 pop+连续天数鼓励、阅读进度条、主题系统（新增「杂志」近白雾蓝预设+衬线大标题）。

**第二遍抄来并上线**（发布 `20261121T201935Z`）：
1. **照片查看器滑动翻页**——系统相册/Day One 式 paged 手势，原来只能点箭头（`PhotoViewer.tsx`）
2. **影像墙「全部/照片/视频」筛选 chips + 格子错峰入场 + 按压缩放**——Day One Media 视图抄法（`photos.tsx`）
3. **统计数字滚动动画** `useCountUp`——统计页四宫格 / 日历月小结 / 我的三栏数字，挂载与变化时缓出滚动（`motion.tsx`）
4. **列表底部「每日一句」**——Diarly 首页名言卡，衬线居中+按日轮换 14 句（`DAILY_QUOTES` + `index.tsx` listFooter）
5. **编辑器内联心情/天气行展开动画**——FadeIn 入场替代瞬间出现（`write.tsx`）
6. **照片日历格**——Happyfeed/1SE/卡片日记式：有封面照片的日子照片铺底+白字日期+篇数角标，无照片保持心情色软底（`Charts.tsx` CalendarMonth，发布 `20261121T202212Z`）

**看过但决定不抄**：
- Momento 顶部周条导航：与日历 tab + 今日卡重复
- Moodnotes 脸部情绪滑杆：需定制插画资产，MoodIcon 已覆盖
- stoic 2×2 仪表盘卡：我们是列表流主页，模型不同
- Daylio 活动图标矩阵：标签系统已等价
- flomo 聊天式输入：产品模型不同
