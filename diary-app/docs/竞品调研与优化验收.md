| 产品与来源 | 公开展示的界面与功能 | 本项目采用的方向 |

## 已落实的改进

- **文字与界面：** 导航、按钮、表单和数字使用系统字体；日记标题、正文与摘要跟随阅读字体设置。统一标题行高、辅助文字对比度、主题圆角、按钮及字段状态；字体预览显示实际字体。桌面阅读区适配，手机使用完整视口。
- **加载：** 去除字体阻塞与 Web 固定启动等待。字体以 CSS unicode-range 按需下载，保留每种字重全部 30,928 字符；字体加载失败时使用系统字体。
- **动效：** 支持系统“减少动态效果”的实时变化；动画卸载清理；开关使用 transform；标签、弹层、侧滑、引导和页面切换遵循偏好。
- **输入与导航：** 新建显示“完成”，编辑显示“保存”；1.2 秒自动保存；退出、后台、刷新保护；已完成日记不会误降为草稿；保存失败不跳转成功页；搜索历史删除不触发搜索。
- **大数据：** 搜索按数据变化建立索引；回顾时间线、隐藏列表、照片墙、照片缩略条、人物和地点日记按可见区渲染；统计关键词仅在相应页签计算。
- **隐私：** 收藏、草稿、数量口径排除隐藏条目；隐藏详情、编辑深链、回收站先验证再挂载；验证仅在内存中保存；应用锁启用时隔离底层内容。
- **本地可靠性：** 串行持久化防止旧保存覆盖新保存；清空取消待写入；JSON 导入校验；设备锁不会被外部备份覆盖。
- **同步：** 逐篇记录已同步版本；保留网络等待期间的新编辑；处理删除墓碑；冲突选择真正完成；分页读取；验证码绑定账号；账号操作失败如实返回。
- **备份：** 手动备份包含照片、录音、视频和封面的实际字节、完整性摘要；恢复先写持久化附件，失败回滚已写附件。附件总量上限 25 MiB，文件上限 50 MiB，超限或缺失有明确反馈。自动备份仍是本机快照。旧 JSON 备份兼容，但不承诺补回从未打包的媒体。
- **真实状态：** 保存与同步依据本机持久化和当前版本云回执分别展示；定位失败保留原地点，支持手填；反馈真实写入独立服务并取得回执后才清空，失败可恢复草稿。示例照片与设备照片分开，取消选中真正移除。
- **回顾与提醒：** 年度情绪格点与可访问日期列表可打开当天所有原文；记忆胶囊可选择时间范围、排除标签，最多展示4条。提醒按每日/工作日/周末/自定义生成计划，权限拒绝和安排失败不报成功；网页明确只保存偏好，不发送后台定时通知。
- **部署：** nginx 为 JS/CSS 开 gzip，哈希资源长缓存，HTML 强制重新验证，云接口不缓存；独立反馈服务开机启动，只监听回环地址；发布等待构建标识一致，保留旧版本与配置，可回滚。

## 性能证据

| 项目 | 优化前 | 优化后 |
| --- | --- | --- |
| 常用界面两种字重下载 | 31,393,024 bytes OTF | 1,096,764 bytes WOFF2，减少约 96.5% |
| 字体不可用 | 根布局等待字体，可能白屏 | 系统字降级；本机测试 227 ms 出现可操作按钮（不代表线上 SLA） |
| 5000 篇回顾时间线 | ScrollView 一次挂载全部记录 | 浏览器回归只挂载 9 条附近记录 |
| 自动草稿保存间隔 | 5 秒 | 1.2 秒，并覆盖退出、后台等路径 |
| 线上首次到首页传输（单次观测） | 38,470,030 bytes | 2,014,968 bytes，约减少94.8%；界面无正文字体请求 |

字体分包总文件大小并未按相同比例减少：主要收益来自按当前文字只下载需要的子集。实际网络耗时与设备、连接、缓存有关。

## 验证边界

- 浏览器真实流程与本地数据层已测试；CloudBase 真实账号登录、跨设备往返和生产数据库权限规则，需要真实测试账号/云控制台权限，不能用本地模拟测试代替。
- iOS/Android 完成配置解析、依赖和素材引用检查；未完成真机录音、相机、后台、推送、生物识别测试，也未重新签名发布 App。
- 当前裸 IP 使用 HTTP；HTTPS 需确认域名/证书方案。涉及浏览器麦克风、定位等能力仍受安全上下文限制。
- 25 MiB 以上的媒体档案需要后续分卷/流式归档能力；当前会拒绝并解释，不会生成表面成功却不完整的备份。
