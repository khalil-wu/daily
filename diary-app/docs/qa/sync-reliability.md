# 保存、同步与账号可靠性验收

更新：2026-11-21。以下将本地可重复验证和真实 CloudBase 验证分开记录，避免把注入测试当成线上成功。

## 已实现与本地通过

- 保存页以实际 AsyncStorage 成功写入的快照判断本机保存，以当前日记内容 SHA-256 与云端确认指纹一致判断同步。开启开关、旧版本回执、本机模拟账号均不能显示云同步成功。
- 同步保存开始时的逐篇版本；上传期间新增、修改、删除保留用户的并发操作。永久删除负载不携带正文和附件，冲突逐篇比较、逐篇选择。
- CloudBase 更新采用 `_id + uid + updatedAt` 条件更新，写入序号单调递增。新增采用按账号和日记 ID 得出的确定性文档 ID；新增和更新都检查服务端回执。
- CloudBase 媒体接入 `uploadFile` 与 `getTempFileURL`，路径为 `diary-media/<uid>/<kind>-<sha256>`。拉取后校验字节数与 SHA-256，再写入 IndexedDB 或原生文档目录。缓存按账号隔离，同字节的不同本机文件保留稳定引用。
- 附件同步关闭时，保留云端既有附件，不上传本地文件地址；标签同步关闭时保留远端分类字段。此类情况仅报告部分同步，不确认完整版本。
- 标签、人物、日记本，以及外观、提醒、写作目标均有实际同步逻辑。不同字段并行修改合并，同字段同时修改以本机选择为准；首次登录另一设备以默认值作为基线，避免默认设置覆盖已有云设置。AI 密钥、服务授权、应用锁不上传。
- `wifiOnly` 检测到移动数据或无法确认网络类型时暂停，界面说明当前平台限制及关闭限制后的重试方式。不会把未知类型冒充 Wi-Fi。
- 本地模式、各本机账号、各 CloudBase 账号使用独立数据空间。只有用户明确选择“导入本地模式的日记”才复制 guest 日记到账号。退出后恢复 guest；再登录恢复对应账号。注销只清理该账号，其他账号保留。
- 自动快照按账号隔离；旧快照在加载原账号时一次性归属，账号空间与同步回执不进入可导出备份。手动附件备份上限 **合计 25 MiB**，JSON 文件上限 **50 MiB**。
- 隐藏日记在保存页、冲突比较、备份与导出入口仍受设备验证约束。导入只有实际持久化成功后才显示成功。

## 真实 CloudBase 待验证

尚无可使用的隔离测试账号或控制台权限；没有发送测试短信或邮件，没有据此宣称线上同步已验收。

所需配置：

1. 两个专用测试账号，以及其中一个账号在两个浏览器上下文登录。现有登录支持邮箱/手机号密码，邮箱注册可能触发验证邮件；不要使用真实用户邮箱或手机号做无授权测试。
2. `diary_entries` 集合读写规则按 `uid == auth.uid` 限制；同集合 `kind: metadata` 行保存上述非秘密设置。所有列表查询均分页。
3. 云存储允许当前用户读写自己的 `diary-media/<uid>/*`，并禁止跨账号读取。浏览器临时下载 URL 的 CORS 必须允许当前站点，存储配额需可用。数据库网关继续使用现有 `/cb` 代理。
4. 验证 `.where(...).update()` 返回更新数量、自定义 `_id` 新增支持、`deleteFile` 返回值，以及 `auth.deleteUser` 可用性。失败必须有错误提示，不能显示成功。

验收场景：文字与照片/音视频跨上下文拉取；刷新后离线播放；两端同时编辑同一篇；同步途中断网/恢复；上传拒绝与配额耗尽；关闭各同步选项；A → B → A 切换；B 无法读取 A 数据；删除后旧端不会复活；注销回执及云附件删除。

边界：客户端注销清理云端当前记录引用和本机缓存中已知的文件。历史失败上传产生且未被任何记录/本机缓存登记的云端孤儿文件，需要后台按账号路径列举与清理；客户端没有云存储管理员列举权限。此部分不能仅凭数据库行删除视为完成云存储生命周期治理。
