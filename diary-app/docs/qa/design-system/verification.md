## 实现结果

- 页面标题、导航、按钮、表单、数字和状态采用系统无衬线字族。日记标题、正文、摘要显式选择阅读角色；宋体、黑体、楷体及既有字号、行距、正文宽度和卡片偏好均保留。内置原生字体未就绪时回退系统字体；网页用 CSS 字族回退，原生粗体使用真实半粗字族。
- 共享控件统一至少 44 逻辑像素触控目标；输入框及必要控件边框使用独立对比度颜色。文字、状态、危险动作、禁用控件和焦点分别定义颜色。普通卡片沿用风格圆角；清冷、墨白、旧纸使用描边且不加投影。
- 设置开关从行标题取得可访问名称，父级行不再作为禁用按钮包裹开关。补齐 React Native Web 在 switch、radio、tab、checkbox 角色下缺失的空格键激活，保留 Enter 单次触发。
- 外观缩略图反映当前明暗模式与强调色；同一批短记、长文、三张真实照片和控件样例可在六种风格间比较。预览标明示例内容，不读取用户日记。
- 网页键盘焦点从当前主题取得颜色，输入焦点与主题一致。阅读偏好不影响菜单字体，字体失败不阻止普通写作。
