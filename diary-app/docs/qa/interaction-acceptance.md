# 公共浮层与媒体交互验收

验证日期：2026-11-21。仅使用本地预览 `http://127.0.0.1:8765` 与独立合成浏览器数据。对应构建 `entry-f4296bc43bbbeb9b96764dda80444ec2.js`。

## 已落实

- BottomSheet、PopDialog、照片查看器使用单一命名模态；遮罩不占 Tab 顺序，网页背景隔离；Tab 留在浮层，Escape 关闭，关闭后回到触发点。支持普通与减少动态效果；中途关闭可清理动画与背景状态。
- 标签、人物、人物编辑、日记本空名称及生日格式错误在字段旁显示，保留输入；权限结果在面板内显示。网页相册说明文件选择方式，网页通知说明当前不支持后台提醒；麦克风授权真实调用浏览器权限，并立即停止测试用流。
- AI 同意说明可滚动，两个固定操作纵向排列，320×568 深色最大字档下可完整点击。日期面板日期标题可折行，底部确定可达；时间轮支持键盘与辅助操作，卸载清理定时器，减少动态效果时不平滑滚动。
- 照片浏览背景不透明，前后切换和关闭具有明确名称；箭头使用深色底，浅色图片上仍可见；缩略条按需挂载；照片墙提供“查看日记”，同 URI 在不同日记的索引与来源保持一致。
- 标签、人物、心情及颜色选项具有勾选语义；网页空格键可切换选择。
- 照片墙、照片缩略条、人物日记与地点日记列表虚拟化；原有隐藏、回收站、发布状态筛选保留。
- 足迹页明确为地点分布示意；有坐标与仅名称分组。相邻地点聚合后可选择每个地点，再查看该地点所有日记。坐标平均只计入完整有效经纬度，不给名称记录编造坐标。
