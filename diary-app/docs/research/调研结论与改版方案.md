# 记得日记：全页面调研结论与改版方案

2026-11-21 · 国内扩展研究版。用户要求先调研全部页面、扩大国内样本，再改视觉；此阶段未修改产品代码、未部署。此前已完成的稳定性修复仍保留在本地工作区。

## 结论

**建议把记得定位为“轻松写下、安心保存、愿意回看”的私人日记。** 本轮将国内及中文市场研究从4款扩展为18款来源已核对的产品：15款日记、手帐和情绪记录主样本，另有心岛、flomo、一言3款相邻产品。部分商店提供者仅为中文个人名，不据此补造公司注册地。Day One、Daylio保留为补充；卡片日记与MOODA独立对照，不计这18款。没有提前指定哪一家为主模板，也没有将原三套颜色草案定为最终方向。

扩展后的证据更支持先调整任务分工：文字日记、心情快记、语音记录可以共用可靠保存与回顾；信纸/排版作为可选表达方式；设置、同步和隐私状态要清楚。当前最大问题仍是信息角色和真实状态不一致：全局宋体影响小控件辨识，暖棕换色无法解决保存提示、错误恢复、弹层遮挡和导航重复。

可直接浏览[国内产品截图对照板](domestic-comparison.html)，按类型筛选并放大；每款卡片都有官方来源、实际观察和限制。[页面证据覆盖表](coverage-matrix.md)区分图、官方文字和未见，避免把“宣传写了功能”当成“页面实测通过”。

扩展研究实际改变了哪些判断：

1. **主题不能只比较棕、蓝、绿。** 墨记的文字纸页、罐头的信纸预览、念念的手绘系统、声间的森系声音空间，差异首先是内容密度、字体职责、入口与装饰范围。原三色设计板只验证部分颜色和可读性，不能独自代表完整候选方案。
2. **字体分工比选一个字库更重要。** 墨记两端公开图的字形不同；一本/吾记偏中性UI，一言偏作品排版，Moo/念念有书写气质。记得需要稳定UI字体与可选正文风格，预览真实长中文，保持用户已有偏好。
3. **回顾应由用户控制。** 往年今日、月份照片、声音回听、可排除标签的随机回顾解决不同任务。可以先用现有数据实现可靠原文回看，再评估生成总结。
4. **保存反馈必须准确。** 墨记官方帮助专门解释首次同步、跨系统账号与恢复；多款政策/权益页面有对应关系或口径差异。记得界面必须匹配自身实际能力，本机保存、云端确认、阅读导出、完整恢复分别说明。
5. **装饰可以可选，功能应完整。** 保留既有日记本、人物、媒体、搜索和统计能力，通过信息层级与渐进展开减少负担；不将全面优化变成删功能的简陋演示页。

## 视觉系统提案

交互式比较：[三套色彩小样](design-directions.html)。这是同一组页面的研究小样，**尚未应用到产品，也不是扩展研究后的最终方案**；它只验证纸页/清昼/森晴在五种页面的浅深色与字体职责。完整风格选择还要使用新增国内证据。

保留已有用户的主题选择。候选应比较清爽文字、温柔纸面、可选手帐表达的完整页面：相同短记、长文、多图、空态，配合首页、输入、心情、统计、弹层、设置和深色。新用户默认主题仍待这份比较收敛，不再根据前4款样本先指定“纸页”为默认。

| 角色 | 规则 | 原因 |
| --- | --- | --- |
| 界面字体 | 系统中文无衬线，用于导航、按钮、表单、日期和数据；标题用统一600字重 | 一本/格志/Day One/Daylio的可见工具层级共同支持清晰UI；系统字体也减少首屏负担 |
| 日记字体 | 正文独立选择宋体/黑体/楷体，预览长段、标点、粗体与列表；可选界面跟随阅读字体 | 保留私人阅读偏好，设置文案与实际作用范围一致 |
| 字号 | 页面标题22–24，正文输入/阅读16–18，功能行15–16，辅助12–13；不把9–10px用在关键数据 | 320px、中文长标签、大字档都能读懂；数字等宽，单位用次级层级 |
| 行距 | 阅读1.75–1.9，控件1.4–1.55；长文宽度单独控制 | 读日记与扫设置表的节奏不同 |
| 间距 | 4/8/12/16/24/32；页面水平20（小屏16），卡内16 | 跨页对齐有规律，减少每页手工调像素 |
| 圆角 | 控件、卡片、弹层各固定一类token；圆形只给头像/表情/单个浮动主动作 | 修复首页方角而选择器仍大圆卡的主题断层 |
| 色彩 | 背景中性，操作强调色少量使用；心情色、日记本分类色、危险色互不替代 | 用户能靠颜色辨认意义，而不是辨认随机装饰 |
| 阴影 | 内容卡主要用留白/轻边界；浮层与主动作才需要明确层级 | 避免所有卡都漂浮、暗色阴影浑浊 |
| 选中状态 | 颜色+勾选/描边/文字至少两种线索；不能仅改变淡底色 | 色弱、低亮度与读屏都能分辨 |
| 图片装饰 | 仅在引导、空态和可选封面少量出现；表单/错误页不反复放同一山景 | 让真实日记照片成为视觉主体，减少页面加载与内容噪声 |

提案色值属于为记得设计的候选，不声称是从竞品源码复制的官方token。最终以设计板实时对比度和全页验证为准。

## 逐组改法

完整49行详见[逐页矩阵](current-pages.md)，每组触发条件、实施动作和验收详见[实施优先级](implementation-priorities.md)。按以下顺序拆分，避免一次重写所有业务。

### 1. 首页与查找

- 保留现有五个底部入口的功能位置，第一轮不凭主观偏好删导航。
- 顶部明确当前日记本，搜索为稳定入口；整理“全部/日记”实际结果重复的问题，收藏、草稿和置顶作为清晰筛选状态。
- 日期分组、标题、2行摘要、元信息、缩略图形成固定扫描顺序。收藏图标全应用一致，草稿/私密/已删是状态差异，不各造一套卡。
- 今日卡默认只占小区域：一个开写动作、可收起的心情/灵感，目标进度不过度抢占内容。
- 搜索的固定“热门关键词”改为真实常用标签或明确的建议词；条件可见、可清空，回列表保留位置。

### 2. 编辑、阅读与选择器

- 自由写作直接进入正文；日期/日记本等信息紧凑，AI、人物、标签和附件按需要展开，中文键盘出现后仍能看到保存状态和关键动作。
- 普通编辑完成回到原文；新建首次/里程碑才需要可跳过的鼓励，避免每次保存强制进入全屏庆祝。
- 文字格式与附件分组，主工具栏只保留高频工具。日期、心情、标签、人物使用同一选择器结构：标题、当前值、明确完成/取消。
- 图片选择明确分为设备导入、已有附件、可选示例素材；不将样例照片叫“最近照片”。
- 语音先保证原声保存/试听与失败重试，识别原文和AI整理区分；无图、无转写的录音也有完整列表项。
- 模板显示实际问题与段落结果；已有正文时明确“追加到正文”，装饰信纸不与文字结构模板混淆。
- 定位失败保留原内容，提供重试/手动地点；绝不代填固定杭州坐标或距离。
- 阅读界面正文优先，时间/天气/地点/人物弱化，编辑只保留一个主入口，图片查看可回到来源日记。

### 3. 日历、回顾、统计与相册

- 今日、选中日、有记录、心情四种信息使用不同线索；点选后列表同步，返回保持月份。
- 回顾先展示原文，再提供自己写总结/可选AI；模板参考格志“需要时才出现”的方式。
- 往年今日/随机回看提供时间与标签范围，隐藏记录默认排除；跨日期主题先利用日记本/标签/人物，不马上追加“故事串”数据体系。
- 统计先回答“记录了多少、何时写、心情如何变化”；复杂关联进入详细页。显示时间范围和有效样本量。
- 年度像素支持键盘/列表替代，小色点不承担唯一点击入口；能跳回当天原文。
- 相册虚拟化并按日期分组；没有真实地图服务时使用“地点回忆”及可靠列表，不用假精确点位。

### 4. 我的、设置、账号与数据

- 我的页聚合个人记录与少量常用入口；完整设置按账号、写作、外观、隐私、数据、帮助分组，消除重复开关。
- 外观先选一套完整主题，再进入高级颜色；缩略预览反映当前主题和实际深浅模式。字体只在一个位置配置。
- 账号页展示未连接/已连接/同步中/失败/上次成功，隐藏未实现的“同步照片/仅Wi-Fi”等承诺，或先真正实现再开放。
- 备份、快照、阅读导出三者分别命名；展示内容范围、附件容量、目标位置，隐藏记录在导出前明确授权。
- 反馈输入不得清空后假称收到；服务不可用时保存草稿或提供导出。关于页移走离线/冲突演示入口，帮助与当前真实能力同步更新。

## 动效与性能验收

动效参数是记得的候选工程标准，不是竞品实测结论：点击反馈约100–160ms，弹层约180–240ms，页面过渡约220–280ms；列表不逐条等待入场。优先透明度和transform，滚动时避免逐帧React状态更新。减少动态效果关闭位移/缩放，保留即时状态反馈。

应完成的验证：

- 320/390/760/1280宽度，长中文、空态、样例数据、大字号与深色；主题不仅抽查首页。
- 拼音组合输入、连续听写、选区、撤销、快速返回、刷新、键盘遮挡、保存失败。
- 5000篇列表/检索与大量媒体墙；浏览器录制长任务/滚动表现，原生真机再测帧率，不能把单次截图称作“丝滑”。
- 原生权限、录音、相机、提醒、生物识别、后台恢复；目前只有静态原生配置检查，尚无真机验收。
- TypeScript、80项现有单测、11项浏览器交互、媒体备份跨隔离环境恢复；修改后补针对新问题的行为回归。
