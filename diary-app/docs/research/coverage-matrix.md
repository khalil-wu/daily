# 竞品公开资料页面覆盖矩阵

汇总日期：2026-11-21。来源为本轮各组已保存并说明核验范围的研究报告与公开证据。用于回答“具体看到了什么”，**不作主观评分，不把官方声明写成实际运行通过**。没有安装竞品、登录真实账户、购买会员、试用其恢复流程或测量原生性能。

## 标记与统计口径

- **图**：研究者已实际查看官方发布的界面图。图号对应产品名链接的截图合集；只是入镜，不代表可操作、当前安装版或功能成功。宣传叠图、入口、旧图在单元格中另注。
- **文**：亲读的官方介绍、帮助或条款明确说明。不能据此推断未出现页面的布局、操作步数、成功率。
- **未见**：本轮没有取得相应可核验页面/说明；不等于产品没有该功能。“未见完整页”与“有入口”分别记录。
- **编辑 / 键盘**：阅读详情、排版预览、天气选择都不自动算文字编辑；只有键盘实际入镜才标“键盘图”。中文拼音候选、连续输入与光标行为均未实测。
- **字体 / 主题**：一般页面可证明某种外观，不能证明字体设置能力、精确字库名称、字号参数或全套主题质量。
- **隐私设置**：政策文字、锁图标、锁页、隐私选项页是不同证据；均不等同于加密架构实测。
- **备份 / 恢复**：云同步、阅读PDF/Word/长图、完整可恢复包分别写明；看到同步开关不表示已同步成功。
- **商业页**：素材/商品/会员权益页与商店“含内购”分别记；未购买，不评价支付流程和实际结算。

当前共列 **15款核心日记/手帐/情绪记录样本、3款相邻产品、2款身份待核验或非国内对照**；再附之前的Day One/Daylio，合计22个独立产品。Android与iOS同一产品不重复计数；Moo和MOODA分别列，不把相似名称混为一款。核心/相邻是本轮研究任务分组，不是好坏排名，也不证明每个个人提供者或公司均注册于中国大陆。中国区上架、中文姓名、中文界面本身均不能单独证明主体注册地。

## 从覆盖表保留的研究空白

1. **文字输入实测仍缺**：少数图库有键盘入镜，但没有对任何竞品实际完成中文组合输入、长文光标定位、撤销重做、系统返回保存等测试。
2. **备份恢复实测仍缺**：多数产品只有官方文字或设置入口，没有进行竞品跨设备恢复、原始媒体校验、多端冲突/断网重试。
3. **商业和隐私深页不齐全**：素材商城、会员官网、IAP标记不能代替完整支付流程；政策失配和旧截图已按产品保留，不能为了矩阵齐全填补推测。
4. **动画与性能都未实测**：没有依据宣称任何竞品达到某帧率、响应时间或当前设备上的“丝滑”。后续记得的验收必须使用自身运行数据。
