# 记得日记：优化实施优先级与验收清单

2026-11-21。**这是调研阶段形成的实施清单；当前实施、验收与线上发布状态见[最终验收与发布](../qa/最终验收与发布.md)，不要把本文件的历史问题描述当作现状。** 目标是把现有记得日记的记录、阅读、回顾、媒体、隐私和数据能力做完整、统一、可靠，沿用现有业务与数据，不替换成只有首页和编辑框的演示应用。

依据：[49路由审计](current-pages.md)、[15浮层/失败状态](states.md)、[功能承诺核对](capability-audit.md)。研究范围为 **49路由文件（含根重定向）+ 2布局 + 15种公共浮层/失败状态**；64张路由/主题截图加15张状态截图。竞品范围为15款面向国内及中文市场的核心样本、3款相邻产品及单列的身份边界，资料是公开图/文字/帮助，**不是所有竞品页面的安装版或真机实测**。

## P1-01：中文字体、控件和页面层级

当前`src/components/text.tsx`让按钮、标签、输入、计数一起继承阅读字体，而字体页解释的范围是标题与正文。统一应先定义文字角色，保留阅读偏好的价值。

- 建立系统无衬线UI角色：导航、按钮、表单、标签、数字、状态、图表；阅读角色用于日记标题/正文及用户选择的内容预览。页面标题是否跟阅读风格另作明确规则，不能靠单页覆盖偶然实现。
- 复用NavBar、Button、Input、Row、Card、Chip、列表行与空态的尺寸、内边距、焦点、禁用、忙碌、成功/失败规则。先改共享组件，再遍历49路由；细分角色用有限字号，不再让每页自行发明13—15档字号。
- 预览包含中文长句、标点、繁简/英文/数字、真实表单和图表，不只展示一句漂亮标题。字体下载失败用系统回退，能立即写作；保留现有字体分片和缓存优化。

**验收：** 320/390/760/1280宽，浅/深/系统、默认/最大字档；正文与UI字体作用范围符合说明，正文选择/光标不因切字体跳走；关键文字不再用9—10px承载信息。正常文字对比度目标至少4.5:1，大字/非文字控件至少3:1；主要触控目标至少44×44逻辑像素。不得通过裁切标签、缩小字体或关闭大字来“通过”。

参考：墨记两端字形与官方字体权益有差别；拾柒书页正文与工具分工；Day One官方明确内容字体不改变菜单。精确字体名、色值和性能以记得自己的实际测量为准。

## P1-02：公共状态、模态窗口与可访问性

[15状态实拍](states.md)已发现：Toast被Modal遮罩压暗；320深色大字AI主按钮拆三行；照片全屏透出底层文字；多个dialog未命名，初始焦点落在关闭遮罩；本地导出构建开关祖先被标disabled，但物理点击能操作，源码存在差异。

- 统一BottomSheet、PopDialog、PermissionModal、PhotoViewer、ActionSheet、Toast的层级和主题。输入错误放在输入附近；必要的全局提示显示在当前弹层之上。
- 长说明采用限制高度、正文滚动和可达操作区；窄屏必要时按钮纵排。日期/时间、退出、AI同意、隐私协议、删除都明确标题、结果与返回语义。
- 给照片关闭/前后/缩略图、图标选择、时间轮盘等提供名称、状态和足够目标。明确单一命名模态范围，进入聚焦有效内容，关闭恢复触发点，背景不获焦。
- 先在最新导出构建重查Row/Switch实际DOM；只有复现后再修问题来源，不根据旧构建直接修改无关逻辑。

**验收：** 15个既有状态全部补拍；加长标签、错误、加载、禁用与真实软键盘；320×568最大字档下说明可滚、完整动作可达，按钮词组不逐字挤碎。Tab/Shift+Tab不进入被遮背景，Escape/Android返回只关闭当前层，关闭后恢复焦点与滚动；读屏读到标题、错误和选中状态。照片视图不透出私密正文。开关语义、鼠标、触摸、键盘结果一致。

## P1-03：整套主题和可控动效

当前墨白/清冷共享Card变方角，但心情、外观、写作等仍写死圆角；外观缩略图固定奶茶色。6种风格×10强调色必须有规则支撑，不能把一个首页截图当主题完成。

- 把纸面、卡面、描边、圆角、投影、危险/成功/警示、情绪色和品牌操作色分别定义；自绘图表/弹层/选择器也使用规则。
- 主题预览使用同一条短记、长文、多图和真实设置；高级强调色与阅读偏好保留，兼容既有设置值。情绪语义色与品牌色分离，不因改主题改变历史心情含义。
- 页面进入、弹层、按钮反馈、列表更新分工；避免同一动作连续多轮缩放/弹跳。动画可打断、可反向、卸载清理；减少动态效果时即时完成必要状态反馈。
- PermissionModal/PhotoViewer的原生Modal动画要纳入减少动效规则；图片/字体未就绪不让布局突然跳动，保存与导航结果不以动画完成作前提。

**验收：** 6种既有风格各自覆盖首页、写作、阅读、心情、日历、统计、设置、15公共状态；10强调色做自动对比度检查，典型/边界组合人工看图。连续开关弹层、快速点回退、主题切换中离开无残留遮罩/定时器/闪白。普通和减少动效两种模式功能一致。竞品仿真翻页、漂浮背景的宣传不当帧率证据。

## P1-04：编辑、附件与阅读性能

现有编辑器能力丰富，问题在正文前入口密度、工具状态与保存反馈。照片选择把内置素材标成最近照片；取消旧照片选中却只追加新选择。长文阅读滚动用state可能带动整屏重渲染，录音波形是时间函数装饰。

- 将高频输入/保存保持稳定位置，元数据与AI按需展开；长文、短记、语音均可直接开始，最终仍保存同一日记模型。
- 格式工具显式反映选区与作用范围；模板展示真实问题，空白“使用模板”、非空“追加到正文”，预览撤销不改变原文。图片之间空行、附件删除/排序、标题空白均单独验收。
- 分清设备照片、已附附件和示例素材；如果选择器是附件管理模式，取消选中就应移除对应引用；如果只负责追加，标题和确认动作直接说明。原文件删除需按引用和回收策略处理，不能清理仍被其他日记使用的媒体。
- 原声、转写、AI整理分开。现有录音先保证停止→试听→插入→持久化→重进播放；波形如果没有真实采样，改为明确状态图形。保留视频、封面、暂停与文件失败提示。
- 测量并隔离正文输入、光标、滚动进度、附件加载带来的渲染，不给每次按键或每个滚动帧触发全应用状态更新。

**验收：** 中文拼音组合输入/选词/移动光标/撤销重做/复制粘贴，3万字中文长文和20张图片；打开模板/照片/日期后返回保留选区、正文与滚动位置。所有媒体重载可播放，拒绝权限不假计时，错误重试不删原声。仅本地试验库做存储失败/录音拒绝注入。长文保存失败仍可继续编辑。

参考：墨记官方格式/图片删除修复触发案例，声间第3/5图的录音和键盘状态，格志聚焦编辑、时光/念念完整模板预览；借鉴流程可发现性，不能声称已测这些App的输入延迟。

## P1-05：列表、日历、回顾和统计

- 首页“全部/日记”先明确筛选含义，统一首页/草稿/收藏/置顶/隐藏/人物相关列表；入口重排后所有既有操作仍可找到，收藏图标语义固定。
- `/photos`、`/people/[id]`与大规模人物选择从全量ScrollView.map转为可见区渲染，媒体缩略图按需加载；保留视频类型、日期和到原文关系。已有时间线虚拟化不回退。
- 日历切月/选日→详情→返回保持月份、日期与位置；补记日期、保存后的分组和统计一致，未来日期限制与界面说明对应。
- 回顾负责原文重读与可选自写/AI总结，统计负责有来源的数字。往年今日/随机回忆可按标签/时间排除内容，保护隐藏/删除/草稿范围；无历史时不给持久空卡。
- 年度14px像素不再承担唯一触摸入口，提供足够命中区域、可访问日期列表或分层放大；点位应可进入当日原文。所有图表明确范围、计数、空态；六种心情不被强行当等距好坏分数。

**验收：** 5000条日记包含草稿、隐藏、已删除、同日多篇、跨年/时区边界和多媒体；列表挂载数有稳定上限，不随总条数线性增长，首页既有“仅9条”证据作为参考而非所有列表必须恰好9条。搜索与图表结果和同一可访问数据范围一致；放大字体仍能读图例，键盘/读屏能到原文，所有列表空态/筛选无结果可返回。

参考：吾记/一本/墨记日期索引，念念选日原文，人生笔记原文回忆/媒体分组，Moo周月图与Daylio周期统计；flomo范围设置仅作相邻的可控重读参考。

## P1-06：组织、外观设置与信息架构

- `/notebooks`、标签、人物分别对应分类本、主题/活动、关联对象；保留人物生日/别名/关系和所有既有关联，统一新建/改名/移动/删除的文案与确认。
- 我的/设置/统计的重复入口可收拢，提供明显返回路径；不单凭竞品三Tab或社区首页删掉记得现有五入口。低频功能依然可搜索或在稳定位置发现。
- 外观/字体职责明确，账号/备份中的云状态共享同一来源；提醒分清平台能力、用户开关与系统授权，目标可关闭，不让记录变成强制打卡。
- 关于只展示真实产品身份、版本、帮助和有效政策；演示/诊断归入明确的辅助入口。帮助围绕实际用户困惑，不保留与当前功能不符的承诺。

**验收：** 旧入口/深链有兼容路径；本/标签/人物重命名、移除、批量移动后所有列表计数与搜索一致；键盘/鼠标不依赖长按/悬停/左滑这唯一入口。大字号提醒时间仍可选择，未授权不显示已生效。全部政策/帮助链接可访问且产品身份匹配。

参考：墨记官方跨平台分类操作、时光/念念本架、情绪小助入口分工；共享手帐、粉丝数和素材市场不替换私人管理功能。

## P1-07：账号、同步、备份与真实后端

当前线上是nginx静态Web与CloudBase代理，仓库没有独立业务后端。`wifiOnly/syncPhotos/syncTags/syncSettings`尚未进入同步决策，entries中的附件本机URI也不等于云媒体。只有单个本地entries集合，换账号携带本机内容的规则需明确。

| 工作项 | 实施与验收 |
|---|---|
| 身份与本机内容 | 明确退出保留哪些本机数据、切换账号后是否合并/上传。两测试账号分别创建标记内容，互相查询/直链/同步不可见；换号不自动上传另一账号内容；退出/重登不丢本机记录 |
| 同步范围 | 逐项兑现开关；区分日记文本、标签/本/人物关联、设置、原始媒体。支持项可验证开/关实际请求与结果，尚未实现项如实说明适用性。Wi-Fi限制按平台真实能力处理，不把浏览器无法识别网络类型当成功遵从 |
| 两端版本与冲突 | 两独立客户端创建/编辑/删除/恢复，含离线后同时修改；分页拉全，旧响应不覆盖新编辑，删除不复活，冲突保留可读副本。冲突页若批量处理必须展示影响数量/范围，允许逐篇选择 |
| 媒体云端 | 原始文件上传有真实ID/状态，其他设备从云端能获取；上传失败保留本机附件和重试，文本成功不等于附件全部成功。无需依赖源设备IndexedDB才能播放 |

## 实施顺序与最终验收

1. **P0真实反馈和保护基线**：先修定位/反馈/保存同步文案来源，固定本机版本和输入保护。产物是触发案例、真实状态映射和回归结果。
2. **共享视觉与状态组件**：完成文字角色、间距/控件、主题规则和15公共状态；给首页、写作、阅读、日历、统计、设置及暗色完整对照，使用同一批长内容。
3. **核心流程和大库**：编辑/模板/媒体、所有列表、回顾统计、管理设置按组落地；保留49路由和既有功能，处理重复入口时检查可发现性。
4. **数据与跨端闭环**：同步范围、账号切换、媒体云存储、备份恢复、AI发送；以真实结果填能力表。
5. **发布候选**：同一提交重新导出并验证。仅完成当前研究不触发部署；进入实际实施后用明确发布产物、验证记录和回退路径再发布。
