# 国内手帐与成书产品补充：拾柒、时光手帐、念念手帐

调研日期：2026-11-21。此次新增三款身份明确的国内产品，实际阅读中国区 App Store 当前页面、开发者所链官网、隐私/会员条款，并逐张查看当前网页提供的 **15 张图库**。只形成研究与候选建议，未修改产品代码、未部署、未决定默认主题。

这组产品说明了三种不同需求：**拾柒把日常内容整理成书；时光手帐围绕素材创作和交流；念念手帐把笔记、情绪、角色装扮放进一个陪伴空间。** 可取之处不能只归纳为“小清新”：它们对文字阅读、装饰、付费和公开范围的组织差异，直接影响记录效率。

## 核验方法与限制

- **观察**：本轮打开的官方公开截图或网页上直接可见的布局、文案、入口。不能据静态图证明点击逻辑、输入稳定性或动画帧率。
- **官宣**：开发者介绍和条款中的功能声明，未改写为已实测能力。App Store 隐私标签也是开发者申报。
- **建议**：结合记得当前路由和源码提出的待评审改进，不代表竞品现成功能，不是实施承诺。
- **未见**：未安装应用、未注册或购买，未查看登录后的完整设置、会员支付、云恢复和原生键盘流程；不猜测隐藏页面。

这里的“当前图库”指**访问日 App Store 网页实际提供的图片**。拾柒首页样例仍有 2020 日期；时光有“2023 计划清单”，念念心情页为 2023 年 2 月。其版本号是当前页面所列，不代表图库同步更新到该版本。时光官网新手教程主要为 2018/2019 年内容；其 App 测评详情本轮返回 Nuxt Server error，不能用来补全最新版编辑器。

## 三款带来的新增判断

| 比较维度 | 拾柒 | 时光手帐 | 念念手帐 | 对记得的候选选择 |
|---|---|---|---|---|
| 核心结果 | 可印制的个人书 | 可创作、展示和共享的手帐作品 | 带角色陪伴的手帐/笔记/心情 | 先明确“文字日记 / 手帐拼贴 / 心情快记”的任务差异，再决定默认入口 |
| 装饰位置 | 内容照片与实体书封面；记录 UI 克制 | 素材、模板、封面、社区作品高密度 | 角色、纸片、场景贯穿系统 | 可提供风格选择，但编辑正文区域必须有低干扰方案 |
| 模板能否看清结果 | 成书页可见标题/照片/页码 | 完整页面缩略图、分类和权益 | 页面模板、字体与素材预览 | 现有 7 模板显示真实问题段落，不仅用插画代表模板 |
| 可见回顾 | 日期列表、成书目录 | 本架、日记/作品分组 | 心情月历 + 当日原文 | `/calendar` 与 `/review` 都保留直达原文的路径 |
| 私人与公开边界 | “私密写”与印制；披露需核对 | 私密本/公开本/仅成员可见 | 私人笔记、共享手帐和社区并存 | 用户主动分享前不改变保存范围；保存与分享用不同动作 |
| 商业密度 | 印制页集中展示商品和活动 | 素材中可见 VIP/限免/时光贝 | 素材、装扮、会员并存 | 若未来加入付费素材，选择前显示权益；不要写完后才阻断保存 |

装饰并非天然低效：念念的三入口和情绪表情可以减少“我该写什么”的负担，时光的完整模板预览减少排版试错，拾柒的书页让长期记录有可保存的结果。反过来，主题商店、虚拟货币、社区计数和房间系统会引入新任务与维护成本。决定是否采用，应以记得用户的记录目标为准。

## 字体、主题与性能的下一轮验证条件

1. **字体**：先固定系统 UI 无衬线；正文允许系统无衬线、阅读宋体或后续合法授权的手写字体。需要实际中文标点、繁简混排、数字、英文链接、大字号与长段测试，不从截图反推字体名称。外观切换不能改变表单可读性与输入法稳定性。
2. **装饰密度**：同一条长日记、无图短记和多图日记同时比较三类风格；主题预览使用一致内容。纸纹/贴纸可选，不让背景侵入输入焦点、文本选择和错误提示。
3. **交互**：模板应用后可理解是追加还是替换；重新选主题不修改用户原文；返回恢复原位置；私密保存和公开分享明确分开。截图中的图层、画布、动效不作为已经验证的流程。
4. **动画**：本轮没有原生 App 帧率实测，也没有“某竞品更丝滑”的证据。对记得的后续测试应覆盖页面进入、键盘弹出、模板预览、心情弹层、照片处理、长列表滚动，以及系统减少动态效果。
5. **素材/长文性能**：若采用封面/贴纸，列表用缩略图和可见区域加载；原图在查看时取用；素材下载失败不阻断文字保存。先以真实输入、恢复草稿、离线重进和大量条目回归证明稳定，再讨论装扮动画。
6. **数据兑现**：任何“永久、无限、绝不丢失”都不能从竞品宣传照抄。用跨设备恢复、附件完整性、冲突保留副本和失败重试来证明能力；没有测试的项仍标未验证。

本组扩展的是候选依据：现有 [三套设计板](design-directions.html) 仍是“研究提案，尚未应用”，没有据这三款直接决定最终主题、添加社区或改变后端。
