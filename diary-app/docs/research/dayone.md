# Day One：公开页面与交互研究

调研日期：2026-11-21。证据为实际访问的官方功能页、官方帮助文章和其中的产品截图；没有登录竞品或购买订阅。本文不把官网营销页面配色当作 App 的设计规范，也不把静态截图当成动画性能证据。

## 证据与版本

- [官方功能总览](https://dayoneapp.com/features/)：既有 2026 年资源，也有 2021–2024 年产品图。用于功能定位与历史视觉比较，不能统一称为“当前版本全量实测”。
- [iOS 四种日记视图](https://dayoneapp.com/guides/day-one-ios/journal-views-in-day-one-for-ios/)：List / Calendar / Media / Map；产品截图资源路径为 2024/06。
- [iOS 编辑与格式](https://dayoneapp.com/guides/day-one-ios/editing-and-formatting-entries-in-day-one-for-ios/)：正文介绍包含 2025.5 格式功能；图片部分为 2021 历史界面。
- [Android 编辑](https://dayoneapp.com/guides/day-one-for-android/editing-and-formatting-entries-in-day-one-for-android/)：官方说明上下文工具栏会随输入、选择文本、标题或列表变化。
- [外观设置与字体](https://dayoneapp.com/guides/settings/accessing-the-settings-in-day-one-for-ios/)：明确字体/字号设置作用于日记内容，不改变菜单按钮；支持字体预览、系统字号、自定义字体；列出当前 Journal Themes。
- [深色模式](https://dayoneapp.com/guides/settings/dark-mode/)：分别描述各平台入口；强调色/日记颜色需要兼顾深色阅读舒适度。
- [日记本管理](https://dayoneapp.com/guides/settings/editing-journals/)：名称、说明、颜色、排序、模板与隐藏入口的设置。
- [模板完整指南](https://dayoneapp.com/guides/tips-and-tutorials/templates/)：模板库、我的模板、预览、创建/编辑/删除，以及不同平台限制。
- [提醒](https://dayoneapp.com/features/journaling-reminders/)：时间、文案、日记本/模板的组合。
- [内容隐藏](https://dayoneapp.com/guides/settings/conceal-content-for-additional-privacy/)：区分隐藏预览和应用锁，明确 Web 没有应用锁，不能误以为所有端能力一致。
- [导入导出目录](https://dayoneapp.com/guides/import-export/)：按平台支持不同格式。
- [Web 发布介绍](https://dayoneapp.com/blog/introducing-day-one-web/)：2023 历史文章，说明专注模式和多端阅读/编辑方向；价格和 beta 状态不作为当前依据。

## 逐类页面观察

| 页面族 | 已看见/官方明确说明 | 对记得的启发 | 不直接照搬 |
| --- | --- | --- | --- |
| 日记列表 | 日期侧栏、正文摘要、单张缩略图，细分割线；2024 图顶部切换四种视图，右下新建 | 日期成为扫描锚点，摘要/元信息层级分离，固定写作入口 | 不应机械复制历史四视图导航；记得有独立回顾和统计 |
| 日历 | 月份连续排列；有记录日使用照片/颜色，点日期查看；再次点视图回到当前日期 | 今日、选中日、有记录日三种状态要分清；空日清晰补记 | 记得心情色应该固定语义，不能随品牌强调色改变 |
| 媒体 | 照片/视频/音频/PDF 类型筛选，大面积图片网格 | 真正的已保存媒体库；“设备相册”和“示例素材”严格区分 | 不为完整对标而新加 PDF 附件 |
| 地图 | 真实底图和地点聚合点；点聚合点查看日记 | 无地图服务时改称“地点回忆”，提供可靠列表 | 不能以抽象坐标/随机气泡冒充真实地图和距离 |
| 阅读 | 大段留白服务于文字，照片内嵌，正文是视觉主体 | 提升中文正文可读性；时间/天气/人物弱化；低频操作收至更多 | 不复制英文短行长度到中文字体比例 |
| 编辑 | Aa 格式与附件分开，选中文字才出现相关格式；完成退出；键盘收起触发保存同步 | 高频工具保留一层，附件/格式渐进展开；保存状态真实 | 不把 AI、标签、人物、日期等全部长期堆在正文前 |
| 模板 | 使用前预览；常用模板靠前；可保存自己的模板 | 七个现有模板先做好内容预览与选择，不必须增加数量 | 官方模板库语言存在限制，中文应本地化内容而非硬翻译 |
| 外观 | 字体控制内容而非菜单；每个字体名用本字体预览；明暗/系统设置统一入口 | 将“界面字体”和“日记字体”职责分清；预览使用真实一页内容 | 不需要照搬20字体/9主题；当前记得已有6主题应先完整统一 |
| 日记本 | 颜色是分类辅助，名称和内容才是主角；支持排序、默认模板、隐藏规则 | 书本颜色、应用主题色、心情色分成独立语义 | 不把每本颜色染满整个阅读页造成多色混杂 |
| 提醒 | 时间、文案与目标日记本/模板组合 | 权限状态明确；提醒点击直达写作，重复规则易理解 | SMS、第三方收件等增加运维成本，先不扩张 |
| 隐私 | 预览隐藏≠上锁；按不同平台明确能力 | 应用锁/隐藏/备份加密/云同步四件事分别解释 | 不能因为有密码锁就声称端到端加密 |
| 备份/账号 | 可导出和本地备份；不同平台能力并不相同 | 展示备份包含什么、最后完成时间与失败重试 | 不将仅元数据同步说成媒体全同步 |

## 本轮可直接转化的原则

1. 控件和阅读字体分工；阅读偏好保留，但小字号导航/日期/图表不全用装饰性字形。
2. 大面积背景保持中性，强调色用于唯一主动作和选中状态；分类色与心情色单独定义。
3. 编辑器优先正文，高频入口固定，低频工具按情境出现。
4. 所有“已同步”“已备份”“已定位”必须来自真实完成结果。
5. 不用功能数量作为完成标准；先做通现有49路由。

未验证：当前付费后全部页面、实际登录态、订阅购买、跨端同步速度、设备端动效流畅度。官方文档之间也有历史差异，例如旧 FAQ 对日记本封面的说明与较新的实验性封面文章并不一致，故不据此复制精确配置组合。
