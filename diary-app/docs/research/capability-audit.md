# 功能承诺与实际能力核对

2026-11-21。此表属于调研阶段，只记录观察与改版约束。服务器读取限于已授权站点；没有登录用户账号、发送验证码、提交反馈或部署。

续接说明：下表保留调研时基线。后续已实施并上线的修复、验证结果和仍待真实账号/真机验收的项目，见[最终验收与发布](../qa/最终验收与发布.md)。

| 能力 | 当前证据 | 改版要求 |
| --- | --- | --- |
| 当前线上托管 | nginx 提供 `/var/www/diary` 静态 Web；`/cb/` 代理至 CloudBase；匿名请求代理返回401；源目录没有独立业务后端 | 区分静态站点健康、云网关可达、身份认证、数据库规则、跨设备一致性；401只证明网关鉴权响应，不证明数据库隔离已验收 |
| 日记本地保存 | 本轮前期已补串行写入与可观察失败；80项单测、11项浏览器交互通过 | 状态为“保存中/已保存本机/失败重试”；只有确认写入后才退出编辑器 |
| 完成后云同步 | `write.tsx` 发起 `void actions.syncNow()`；`saved.tsx` 只凭账号与同步开关显示“已保存并同步” | “已保存本机”和“云同步成功”分离；展示本次日记版本的真实同步状态，不根据开关推断成功 |
| Wi-Fi/照片/标签/设置同步开关 | `wifiOnly`、`syncPhotos`、`syncTags`、`syncSettings` 在全库检索中仅有类型/默认值/设置页读写，未进入同步决策；CloudBase上传主体是 entries | 不能保留可点却不生效的设置；已支持的能力明确展示，未实现项隐藏或如实标注；标签/日记本归属迁移要有真实数据方案 |
| 云同步并发 | 前期已修本机编辑覆盖、删除复活、逐篇版本、分页、冲突选择 | 仍需测试账号完成两设备往返/网络断开/失败重试，不能只凭本地模拟称“后端全部OK” |
| 账号切换 | 本机 AppState 有单一 entries 集合；账号与本机记录共存 | 设计明确“退出保留本机内容”和“换账号后是否上传本机记录”；避免用户无意将旧账号内容带到新账号 |
| 媒体保存 | 图片/视频/录音本机持久化，浏览器IndexedDB；前期已实测新环境恢复后校验一致 | 区分设备照片、本地附件、示例素材、云附件；不把本机URI当跨端可访问文件 |
| 地点 | 定位失败 catch 存入固定杭州地点；预置地点写固定距离 | 权限拒绝/超时保留原值并给手动输入；仅真实坐标/地理编码才能显示当前位置或距离 |
| 足迹地图 | 目前抽象点位图，没有真实地图底图；部分样例无坐标 | 可以诚实提供“地点回忆/足迹概览”，不承诺精确地图；无坐标记录只用地点列表 |
| 天气 | 用户手动选天气与温度 | 文案保持“记录天气”，不能称自动获取实时天气 |
| 意见反馈 | 帮助页清空输入并提示“我们已收到”，没有发送接口 | 先提供可保留/导出的反馈草稿或配置真实反馈后端；发送成功必须有服务端确认，失败保留原文 |
| 录音与网页权限 | 前期修复假录音、持久化和播放器；裸IP HTTP不是安全上下文 | 当前地址明确说明浏览器录音/定位受环境支持限制；不能降级成模拟成功；用户已选择先完成IP，不把域名作为本次阻塞 |
| 自动备份 | 每7日本机快照，和用户数据处于同一设备沙盒 | “本机快照”与“可迁移媒体备份”不同，卸载/清站点数据会影响本机快照 |
| 手动备份 | 前期新增自包含媒体JSON，25MiB附件/50MiB文件上限；跨隔离浏览器校验/播放通过 | 展示范围、包含附件数量、容量限制、最后完成时间；大档案需后续分卷/流式方案 |
| 格式导出 | Markdown/纯文本/HTML/PDF/条目JSON与完整备份是不同通道 | 先选范围，隐藏内容明确授权；导出用于阅读，完整备份用于恢复，命名和说明分开 |
| AI | 用户自行配置服务、授权；有本地兜底与危机文本处理；隐藏/草稿不发送有测试 | AI在高级设置里明确服务来源与数据范围，普通写作不被配置打断；不把本地规则结果写成云模型已处理 |
| 统计与心情 | 依据记录计算统计，非专业心理测评 | 展示时间范围、样本量、无数据说明；六种情绪含疲惫/感恩并非严格单一好坏等级，不直接照搬Daylio五档分数 |

后续实施优先级：先清理假成功/不生效设置与范围说明，再统一视觉；真实云账号验收单独列出证据，未完成项明确保留，不能被截图或单测通过掩盖。
