# 记得日记 · 产品介绍与上架资料

## 一句话介绍

**记下生活，记得自己。**

一本私密的、本地优先的个人日记。它帮你写、帮你记，也记得你写过的人和事。

## 副标题 / 短描述（30 字内）

私密日记 · 身边人与「记得」AI

## 商店长描述

记得日记是一本属于自己的日记本：所有内容默认保存在这台设备上，不上传、不公开，不需要联网就能完整使用。

**写下这一刻**
- 干净的写作页：标题、正文、心情、天气、地点、标签，想到什么写什么
- 照片、视频、录音与实时听写，声音可以直接变成文字
- 列表、待办、引用、加粗斜体——Markdown 习惯的排版都在
- 写不下去时，「记得」会顺着你的原文问几个具体的问题，帮你接着写

**身边人**
- 在日记里标记「和谁在一起」，每个人都会在这里有自己的一页
- 别名、关系、生日、备注；按人回看所有写到 TA 的日记
- 只保存在本机，对方不会收到任何通知

**「记得」AI 助手（可选，默认关闭）**
- 追问：写不下去时，顺着原文的细节接着问你
- 整理：帮你补上标题、心情、标签和身边人的建议，一键采用
- 理顺：把口述的碎碎念整理成通顺段落，不改写你的意思
- 回信与回顾：写完后回一封短信；每周、每月为你做一份回看
- 隐私边界：只有你主动操作的日记文字会发送到你自行配置的服务；照片、视频、录音、位置从不发送；隐藏与已删除的日记永远不会发送。不开启时，本地追问与整理建议依然可用

**找回与回顾**
- 周记、时间线、年度回顾与里程碑
- 全文搜索，按心情、标签、身边人筛选
- 日历视图，随手补记过去的任何一天

**属于你的**
- 六套风格与十个强调色，深色模式
- 应用锁、Face ID、隐藏日记、回收站 30 天找回
- 一键导出 Markdown / PDF / 纯文本 / JSON，数据永远可以带走

## 云端接入（腾讯云开发 CloudBase）操作清单

代码已就绪（`src/services/cloud.ts`，基于 `@cloudbase/js-sdk` + `@cloudbase/adapter-rn`），以下步骤需要在腾讯云控制台完成：

1. 注册腾讯云账号（需实名认证）→ 控制台「云开发 CloudBase」→ 新建环境（选免费体验版，3000 资源点/月，每半年可续）
2. 把**环境 ID**（形如 `jide-diary-xxxx`）填入 `app.json` 的 `extra.cloudbase.env`，region 默认 `ap-shanghai`
3. 「身份认证 → 登录方式」开启：**邮箱验证码**（选择「内置邮件代发」，零配置可用，有每日发送上限）、**账号密码登录**；手机号短信验证码同样需要开启（见第 5 点）
4. 「数据库」新建集合 `diary_entries`，安全规则设为仅本人可读写：`{"read": "doc.uid == auth.uid", "write": "doc.uid == auth.uid"}`；字段：uid、entryId、updatedAt、data
5. 短信：2026 年 11 月起 CloudBase 已停用默认签名短信包——需在「短信」里申请自有签名+模板（个人可申请，需审核）后才可用手机验证码；邮箱验证码不受影响
6. 免费环境记得每半年在控制台续期一次，欠费/到期会暂停服务

已实现的能力：

- 邮箱验证码登录/注册（内置邮件代发，无需自建 SMTP）、邮箱密码登录/找回
- 手机号 + 短信验证码登录/注册（自动注册），验证码找回密码（需先过短信签名审核）
- 登录后日记同步到云端，跨设备合并与冲突处理沿用现有协议
- 会话自动恢复（RN 端 mmkv 持久化）；未配置云端时应用保持纯本地可用（测试与演示模式）

未做：照片/视频/录音的云端上传（二期用 `app.uploadFile` + 云存储实现）。
